Website activation

Activation

Nothing to type on the remote

The app shows a QR code and a 12-character code. Use your phone to register the device, then return to the TV.

1
Open the app on the TV

The QR code and the TV code appear on the activation screen.

2
Scan the QR code or enter the code

Point your phone camera at the QR code. It opens this page with the code filled in.

3
Register the device and go back to the TV

The device is recognized by its code in a few seconds.
