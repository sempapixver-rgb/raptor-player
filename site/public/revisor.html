How to test Raptor Player

Information for review in the Amazon, LG and Samsung stores.

Raptor Player is only a video player. It does not include its own videos, ads or purchases. To test it, simply use the public sample videos included in the app.

How to test

Amazon Fire TV / Android TV

  1. Install the app and accept the terms on first launch.
  2. On the activation screen, choose Test the player (sample videos).
  3. Use Play/Pause, forward, rewind, Back and the Previous/Next buttons.
  4. When a clip ends, the next one starts automatically.

LG webOS

  1. Install the IPK and accept the terms on first launch.
  2. On the activation screen, choose Activate TV to see the QR code in focus, or Test the player (sample videos).
  3. The code shown on the screen identifies the device on the activation website.

Samsung Tizen

  1. Install the WGT package in developer mode and accept the terms.
  2. The flow is the same as webOS: an Activate TV button with a QR code and a sample-videos button.
  3. The interface and player are the same as the LG version.

What the app does

• Plays the four public sample videos.
• Seeks forward and backward, with a navigable progress bar.
• Automatically plays the next video at the end.
• D-pad navigation, media keys and the remote's Back button.
• Identifies the device by MAC code, with a QR code for the website.
• No ads, no in-app purchases and no social sign-in.

Data and permissions

The app stores only the device identification code and usage preferences on the device itself. The website is used only to register that code. There is no collection of history, location, camera, microphone, contacts, tracking or advertising. Full details are in the privacy policy.

Raptor Player does not provide, host or distribute content. It only plays the sample videos included in the app.
